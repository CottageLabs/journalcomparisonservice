End User Administrator Registration Form

An End User Administrator is someone who has been given specific authority by their organisation/institution to administer the institution’s account and create End User Authorised User accounts for other colleagues who may need to access the Journal Comparison Service (JCS).
For the avoidance of doubt there can only ever be one End User Administrator per End User.

The End User Administrator can approve as many End User Authorised User accounts as they deem necessary, though it is good practice to limit the number to those colleagues who truly need access.

The End User Administrator is responsible for revoking access to End User Authorised User accounts when someone leaves the organisation or if there has been misuse of the account.

# Journal Comparison Service

The Journal Comparison service was a [cOAlition S](https://www.coalition-s.org/) run service to enable publishers to securely share
journal pricing and service information with institutions without sharing the information with each other.

It enabled institutions to compare the services and prices of different publishers, and to make informed decisions
based on that information.

The service was built and maintained in production by [Cottage Labs](https://cottagelabs.com) between 2022 and 2025,
when the service was sunset.

This code repository contains the code for the Journal Comparison Service as it was at the time of sunsetting.  Note
that the commit history before that is unavailable due to the private nature of the service and the data it contained.

To see the original README, please see the `README.original.md` file.

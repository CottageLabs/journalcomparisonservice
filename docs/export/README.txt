# Journal Comparison Service - Data Download

This dataset has been downloaded from the cOAlition S Journal Comparison Service. Use of the dataset is subject to the the Journal Comparison Service Acceptable Use Policy (https://www.coalition-s.org/wp-content/uploads/2022/05/JCS-Acceptable-Use-Policy.pdf).

A copy of the Journal Comparison Service Acceptable Use Policy has been included with this data download.

By using this Service, you acknowledge that your access to the Service is subject to complying with the applicable competition law rules. In particular, you agree that you will not, directly or indirectly, share with or make available the information provided by the Service to non-authorized persons, and in particular to publishers.

Note: When you download all publisher data in one file, you will be provided with some publisher data which relates to the FOAA framework and some which relates to the IP framework. We indicate which framework has been used in the downloaded file. Note however the following:

      For publishers that make use of the FOAA framework, cells U-AB will be populated, whilst cells AC - AU will be empty.

      For publishers that make use of the IP framework, cells U-AB will be empty, but cells AC - AU will be populated
